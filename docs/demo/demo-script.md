# SIH Demo Script

Run from the repository root:

```bash
PYTHONPATH=backend .venv/bin/python scripts/run_demo.py
PYTHONPATH=backend .venv/bin/python scripts/run_demo.py --json
```

Walk through the labeled DEMO stages, then apply the Paradip
`congestion_plus_5_days` comparison. Emphasize that baseline data is preserved,
Monte Carlo uses a fixed seed, and unavailable critical inputs are shown
truthfully. Approval and execution are demo-only and have no booking side effect.
